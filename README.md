# Computational Mathematics System

A long-term, modular, and extensible system for studying and implementing the core areas of computational mathematics.  
This project integrates academic rigor (following Schaum’s Outlines and classical textbooks) with modern software engineering practices (modularity, reproducibility, testing, documentation).

## Project Structure

The system is organized into four major domains, following a 4‑week rotating study cycle:

1. **Calculus**
2. **Matrix Operations (Linear Algebra)**
3. **Statistics**
4. **Differential Equations**

Each domain contains:
- Mathematical foundations
- Computational design documents
- Python modules
- Jupyter notebooks
- Tests
- Documentation

## Goals

- Build a unified computational mathematics library over time  
- Reinforce mathematical understanding through implementation  
- Maintain clean architecture, naming conventions, and reproducible workflows  
- Use Python (and later R) to mirror textbook structure computationally  
- Develop a lifelong, evolving system of mathematical tools
